# Asset Library

这里存放已经确认可复用的 G_QMark Visual 母资产。生成测试图不要直接混入正式资产目录。

```text
assets/
  identity/            G_Q、字标和动效
  characters/wenhao/  Wenhao 小火柴人母版和动作资产
  mascot/golden-pup/   金毛幼犬母版和状态资产
  icons/               技术设备与工作流图标
  backgrounds/         可复用背景与纹理（后续）
  readme/              README 展示素材
```

正式资产使用版本号，例如 `golden-pup-waiting-v01.png`。一次性实验应放在项目输出目录或 `examples/`，确认后再进入这里。
