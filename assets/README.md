# Asset Library

这里存放已经确认可复用的 G_QMark Visual 母资产。生成测试图不要直接混入正式资产目录。

```text
assets/
  identity/            G?、黄色圆点和品牌标识
  characters/wenhao/  Wenhao 角色母版和动作资产
  mascot/q-cat/        Q Cat 母版和状态资产
  icons/               技术设备与工作流图标
  backgrounds/         可复用背景与纹理（后续）
  readme/              README 展示素材
```

正式资产使用版本号，例如 `qcat-processing-v01.png`。一次性实验应放在项目输出目录或 `examples/`，确认后再进入这里。
