# Q Cat Assets

用于存放 Q Cat 的正式母版、动作和状态资产。

Q Cat 的默认含义是问题、AI、Agent、好奇心和处理状态。固定特征见仓库根目录 `DESIGN.md`。

建议优先建立：

```text
qcat-neutral-v01.png
qcat-thinking-v01.png
qcat-processing-v01.png
qcat-waiting-v01.png
qcat-confused-v01.png
qcat-complete-v01.png
qcat-peeking-v01.png
qcat-on-laptop-v01.png
qcat-on-nas-v01.png
```

正式资产优先保留透明背景版本。尾巴的问号形态和黄色识别细节需要在第一套角色母版确认后锁定。
