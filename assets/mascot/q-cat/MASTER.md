# Q Cat Mascot Master

Status: provisional specification, no canonical mascot sheet approved yet.

Q Cat is the recurring companion in G_QMark Visual. It should be cute enough to be memorable, but simple and restrained enough to appear in technical and work-related videos without turning the whole visual system into children's illustration.

## 1. Role

Q Cat represents one or more of these meanings depending on context:

- curiosity / question
- AI assistance
- process state
- lightweight reaction
- progress or error feedback

It is not a literal robot assistant and does not need to appear in every scene.

## 2. Stable identity features

Keep these features consistent:

- small rounded cat
- warm milk-gray body
- lighter belly / muzzle area
- simple dark graphite outline
- small warm-yellow collar tag or circular accent
- tail naturally curves into a readable question-mark gesture
- calm, slightly curious default expression

The question-mark tail is the strongest silhouette feature.

## 3. Shape language

Use rounded, compact shapes:

- round head with modest cheeks
- short body
- compact paws
- small triangular ears with softened corners
- thick enough tail to remain readable at small size

Avoid long elegant cat proportions, sharp anime ears or highly realistic anatomy.

## 4. Color

Suggested working palette:

- body gray: `#C8C4BC` or a nearby warm milk-gray
- light belly / muzzle: `#F4F0E8`
- outline: `#30343B`
- inner ears: muted pale pink
- collar/tag accent: `#F2C94C`

Do not introduce saturated rainbow colors into the canonical mascot.

## 5. Face

Default expression:

- dot or short-line eyes
- tiny simple nose
- restrained small mouth
- mild curiosity rather than constant excitement

Useful expression states:

- neutral
- curious
- thinking
- confused
- focused
- pleased
- sleepy / waiting
- error / stuck

Avoid meme faces, huge sparkling anime eyes or exaggerated human-like emotional acting.

## 6. Tail semantics

The tail is allowed to communicate state while preserving the cat silhouette.

Preferred states:

- `?` — thinking, unknown, inquiry
- raised curve — attention / active
- relaxed curve — idle / normal
- straighter upward gesture — realization / success

A literal `!` or `✓` may be suggested through pose or adjacent graphics, but do not mutate the tail into arbitrary symbols in every scene.

The canonical resting tail should still resemble a natural cat tail that happens to form a question-mark gesture.

## 7. Typical interactions

Q Cat may:

- sit beside a laptop or small computer
- lie on a progress bar
- peek from behind a window or folder
- sit on a NAS / local model box
- inspect a small model cube
- sit near a camera
- watch a 3D printer or electronics project
- react to an error message
- accompany Wenhao during explanation scenes

Keep props secondary and recognizable.

## 8. Do not turn it into a robot

Avoid as canonical features:

- metal body panels
- LED face
- antenna
- exposed circuitry
- holographic projections
- robotic joints
- glowing cyberpunk parts

Technical meaning should come from context and props, not from making the mascot itself mechanical.

## 9. Scale

Q Cat should work at several levels:

- 24–48 px micro reaction / status icon
- 64–160 px corner companion
- medium editorial illustration element
- sticker / 3D-print reference in the future

Keep the silhouette clear enough for small sizes.

## 10. First canonical pose sheet

Approve at least:

1. front sitting neutral
2. side sitting with visible question-mark tail
3. walking
4. lying down
5. curious / looking upward
6. thinking
7. confused
8. pleased
9. sleeping / waiting
10. peeking from behind an object

12. interacting with Wenhao

## 11. Canonical approval package

Recommended files:

- `qcat-master-front.png`
- `qcat-master-side.png`
- `qcat-expressions.png`
- `qcat-pose-sheet.png`
- `qcat-colors.md`

Before approval, test the tail silhouette at 32 px and 64 px.

## 12. Never drift without approval

Do not silently change:

- warm milk-gray body
- yellow circular accent
- compact rounded proportions
- question-mark tail concept
- restrained face style
- bright editorial illustration language

A generated cat that is cute but lacks these features is not canonical Q Cat.
